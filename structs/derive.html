Structs

#[derive(Validate)]

The derive macro for structs and enums — field attributes, serde renames and tagging, skip and default, generics and lenient parsing.

With the derive feature, #[derive(Validate)] generates the same API as schema! from attributes on an ordinary struct or enum. Use it when the struct already has other derives (serde, clap, utoipa) or you prefer attributes.

Cargo.toml
vld = { version = "0.5", features = ["derive"] }

use vld::prelude::*;
use vld::Validate;

#[derive(Debug, serde::Serialize, serde::Deserialize, Validate)]
#[serde(rename_all = "camelCase")]
struct SignUp {
    #[vld(vld::string().min(2).max(50))]
    display_name: String,
    #[vld(vld::string().email())]
    email_address: String,
    #[vld(vld::number().int().gte(18).optional())]
    age: Option<i64>,
}

let s = SignUp::vld_parse(r#"{"displayName": "Ada", "emailAddress": "ada@example.com"}"#).unwrap();
assert_eq!(s.age, None);

A #[vld(...)] attribute holds the field's schema expression, pasted as is (the paths must be in scope). A field without it gets its type's default schema, vld::schema::VldType:

TypeSchema
String, bool, char, f64, f32vld::string(), boolean(), char(), number(), f32()
i8 … u64, isize, usizevld::i8() … vld::usize() (type range checked)
Option<T>T's schema .optional()
Vec<T>, HashSet<T>vld::array(..), vld::set(..)
HashMap<String, T>, BTreeMap<String, T>vld::record(..) (.ordered())
serde_json::Valuevld::json_value()
a derived or schema! typevld::nested!(T) (a $ref in OpenAPI)

Implement VldType for your own types to make them inferable. Generic derived types do not implement it; use #[vld(...)] there.

#[derive(Debug, Validate)]
struct Profile {
    name: String,                 // vld::string()
    age: Option<u8>,              // vld::u8().optional()
    #[vld(vld::string().email())] // explicit where it matters
    email: String,
    address: Address,             // vld::nested!(Address)
}

Enums

Enums follow serde's representations, so the same type deserializes and validates the same JSON. The output is the enum itself.

#[derive(Debug, serde::Serialize, serde::Deserialize, Validate)]
#[serde(tag = "type", rename_all = "snake_case")]
enum Action {
    Ping,
    CreateUser {
        #[vld(vld::string().min(2))]
        name: String,
        #[vld(vld::string().email())]
        email: String,
    },
    Move(Point),                       // a derived / schema! type validates itself
    #[serde(rename = "delete", alias = "remove")]
    DeleteUser {
        #[vld(vld::number().int().min(1))]
        id: i64,
    },
}

let a = Action::vld_parse(r#"{"type": "create_user", "name": "Ada", "email": "ada@example.com"}"#)?;
let err = Action::vld_parse(r#"{"type": "fly"}"#).unwrap_err();
assert_eq!(err.issues[0].code.key(), "invalid_discriminator"); // at `.type`
RepresentationInputErrors at
external (default)"Ping", {"Move": {...}}.Move.x
tag = "type"{"type": "move", "x": 1}.type, .x
tag = "t", content = "c"{"t": "move", "c": {...}}.t, .c.x
untaggedthe variant's own shape, tried in orderinvalid_union + each variant's issues ([variant N])

Variants:

  • unit: no content (null / absent);
  • newtype V(T): #[vld(...)] on the field, or none when T has parse_value (#[derive(Validate)] / schema!): vld::nested!(T) is used, and the JSON Schema references T;
  • tuple V(A, B): a JSON array, #[vld(...)] on every field (not with internal tagging, as in serde);
  • struct V { .. }: fields exactly as in a struct (#[vld(...)], rename, default, skip).

Serde attributes: enum tag, content, untagged, rename_all (variant names), rename_all_fields; variant rename, alias, skip / skip_deserializing, other (unit variant for unknown tags), rename_all (its fields). Variant-level untagged, with and deserialize_with are compile errors. Unknown fields are ignored unless the enum has #[serde(deny_unknown_fields)] (see the table above); there vld also rejects extra keys next to the tag of a unit variant, which serde lets through.

The JSON Schema is a oneOf with an OpenAPI discriminator for tagged enums, anyOf for untagged ones. #[vld(lenient)] is struct-only.

Generics

Generic structs work. Their field schemas are rebuilt on every call (non-generic structs cache them, see below).

use vld::schema::VldParse;

#[derive(Debug, Validate)]
pub struct Page<T: VldParse> {
    #[vld(vld::array(vld::nested(T::vld_parse_value)))]
    pub items: Vec<T>,
}

Lenient parsing

#[vld(lenient)] on the struct adds validate_fields() and parse_lenient(). Every field type must implement Default and Serialize. See Lenient parsing.

#[derive(Debug, Default, serde::Serialize, Validate)]
#[vld(lenient)]
struct Config {
    #[vld(vld::string().min(1))]
    host: String,
    #[vld(vld::number().int().min(1).max(65535))]
    port: i64,
}

let r = Config::parse_lenient_value(&serde_json::json!({"host": "h", "port": 0})).unwrap();
assert_eq!(r.error_count(), 1);
assert_eq!(r.value.port, 0); // invalid field fell back to Default

OpenAPI parameters

For utoipa::IntoParams, add #[into_params(parameter_in = Query)] (or Path, Header, Cookie) to the struct; the derive records it and vld-utoipa uses it.

Caching

Field schemas of non-generic structs are built once per process and cached, exactly as with schema!: they must be Send + Sync + 'static, and values captured on first use are frozen.

For limits that change at runtime (settings, plans, feature flags) put #[vld(dynamic)] on the struct or enum: its schemas (and JSON Schema) are rebuilt on every parse, as in generic code.

#[derive(Debug, Validate)]
#[vld(dynamic)]
struct Upload {
    #[vld(vld::number().int().max(settings().max_upload))]
    size: i64,
}

Inside serde

To validate while serde deserializes (one decoder), use vld::de:

vld::deserialize_fn!(fn volume -> i64 = vld::number().int().min(0).max(100).clamp());

#[derive(serde::Deserialize)]
struct Settings {
    #[serde(deserialize_with = "volume")]
    volume: i64,
    #[serde(deserialize_with = "vld::de::parse")] // any VldParse type
    profile: Profile,
}

The vld error becomes the serde error (as text). A deserialize_with field is required unless it also has #[serde(default)].
