## Add the crate

```toml [Cargo.toml]
[dependencies]
vld = "0.8"
```

Or with cargo:

```bash
cargo add vld
cargo add vld --features derive,openapi
```

The minimum supported Rust version of `vld` is **1.85** with every feature. Some integration features need more; see [MSRV](/getting-started/msrv).

## Features

No feature is enabled by default. Everything below is additive.

| Feature | Enables | Extra dependencies |
|---|---|---|
| `derive` | `#[derive(Validate)]` ([guide](/structs/derive)) | `vld-derive` |
| `openapi` | `JsonSchema` trait, `json_schema()`, `to_openapi_document()` ([guide](/openapi/json-schema)) | none |
| `diff` | `vld::diff::diff_schemas` for breaking-change detection; implies `openapi` ([guide](/openapi/diff)) | none |
| `regex` | `vld::string().pattern(...)`, `vld::rules::Pattern` | `regex-lite` |
| `chrono` | `vld::chrono::{date, datetime, time}` ([guide](/schemas/dates)) | `chrono` |
| `jiff` | `vld::jiff::{date, datetime, time}` | `jiff` |
| `time` | `vld::time::{date, datetime, time}` | `time` |
| `decimal` | `vld::decimal()` (`rust_decimal::Decimal`) | `rust_decimal` |
| `net` | `vld::ip_network()` (`ipnet::IpNet`) | `ipnet` |
| `file` | `vld::file()` with size, extension and media-type checks | `infer` |
| `file-advanced` | `file` plus `sha256()` / `md5()`, image dimensions, `require_exif()` | `sha2`, `md-5`, `image`, `kamadak-exif` |
| `string-advanced` | `url_strict()`, `uri()`, `uuid_v1/v4/v7()`, `phone_e164_strict()`, `semver_full()` | `url`, `uuid`, `phonenumber`, `semver` |
| `ts` | `vld::ts`: Zod / Valibot / TypeScript codegen; implies `openapi` ([guide](/integrations/codegen/ts)) | none |
| `fake` | `vld::fake`: test data that passes a schema; implies `openapi` ([guide](/integrations/codegen/fake)) | `rand`, `regex-lite`, `regex-syntax` |

The date features can be enabled together. `vld::date()`, `vld::datetime()` and `vld::time_of_day()` exist only when exactly **one** of them is on; with several, call the backend module (`vld::chrono::date()`). See [Dates](/schemas/dates).

## Integration crates

Integrations live in four group crates, one module per library, each behind its feature (none is on by default). Any set of features can be enabled together, including several majors of one library.

| Crate | Modules |
|---|---|
| `vld-web` | [web frameworks](/integrations/web/overview): `axum`, `actix`, `ntex3` / `ntex4`, `poem`, `rocket`, `salvo`, `warp`, `rama`, `tower`, `tonic`, `common` |
| `vld-openapi` | [`utoipa5` / `utoipa6`](/integrations/openapi/utoipa), [`schemars0` / `schemars1`](/integrations/openapi/schemars) (also aide), `validator` |
| `vld-data` | [`sqlx08` / `sqlx09`](/integrations/database/sqlx), [`diesel`](/integrations/database/diesel), [`sea1` / `sea2`](/integrations/database/sea-orm), [`surrealdb`](/integrations/database/surrealdb), [`redis0` / `redis1`](/integrations/messaging/redis), [`lapin2` / `lapin3` / `lapin4`](/integrations/messaging/lapin) |
| `vld-app` | [`config`](/integrations/config-cli/config), [`clap`](/integrations/config-cli/clap), [`tauri`](/integrations/ui/tauri) |

```toml [Cargo.toml]
vld-web = { version = "0.8", features = ["axum"] }
```

Coming from 0.7's per-integration crates (`vld-axum`, `vld-sqlx`, …): see the [migration guide](/guides/migration#from-07-to-08).

## Prelude

Most code needs a single import:

```rust
use vld::prelude::*;
```

It brings in the `VldSchema`, `VldParse` and `VldInput` traits, the error types (`VldError`, `ValidationIssue`, `IssueCode`, `PathSegment`), the formatting helpers and every schema type. With `openapi` it also exports the `JsonSchema` trait.

The schema constructors are free functions: `vld::string()`, `vld::number()`, `vld::array(...)`. They are not in the prelude, so call them with the `vld::` prefix.

## WebAssembly

The core has no platform-specific code; `vld` (including `vld::form`, used by Leptos / Dioxus apps) builds for `wasm32-unknown-unknown` (checked by `just wasm`). Checks that touch the filesystem (`path().exists()`, `file()`) are not meaningful in a browser.
