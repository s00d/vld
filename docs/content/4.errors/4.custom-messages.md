---
title: Custom messages
description: Per-check messages, bulk overrides, type errors and whole-schema messages.
---

There are four ways to change a message. From the most to the least specific:

| Tool | Scope | Example |
|---|---|---|
| `*_msg(...)` builders | one check | `vld::string().min_msg(3, "Too short")` |
| `with_messages(...)` | many checks of one schema, by key | strings, numbers |
| `type_error("...")` | wrong JSON type | most primitives |
| `.message("...")` | every issue of the wrapped schema | any schema |

```rust
use vld::prelude::*;

let username = vld::string()
    .type_error("Username must be text")
    .min_msg(3, "At least 3 characters")
    .max_msg(20, "At most 20 characters")
    .alphanumeric_msg("Letters and digits only");

let pin = vld::string().len(4).pattern(r"^\d+$")
    .message("PIN must be 4 digits");
```

A per-check `_msg` wins over `with_messages`. `with_messages` is consulted when an issue is built, so it also covers checks added after it; a later call replaces it.

```rust
// Override many checks by key at once:
let code = vld::string().min(3).max(8).with_messages(|key| match key {
    "too_small" => Some("Too short".into()),
    "too_big" => Some("Too long".into()),
    _ => None,
});
```

## Builders with a `_msg` twin

- Strings: `min_msg`, `max_msg`, `len_msg`, `non_empty_msg`, `starts_with_msg`, `ends_with_msg`, `contains_msg`, `pattern_msg`, and every format (`email_msg`, `uuid_msg`, `url_strict_msg`, …).
- Dates: `past_msg`, `future_msg`, `timezone_offset_only_msg`.
- Any schema: `rule_msg(rule, "...")` (see [rule message precedence](/schemas/rules#messages)).

## with_messages keys

- Strings: `too_small`, `too_big` (also `min_bytes` / `max_bytes`), `invalid_length`, `non_empty`, `invalid_regex` (for `pattern`), `invalid_starts_with`, `invalid_ends_with`, `invalid_contains`, `invalid_<format>` (`invalid_email`, `invalid_url`, …), and a rule's key.
- Numbers (`number()`, integers, `f32()`): `too_small`, `too_big` (also the type-range failure of sized integers and `f32`), `not_positive`, `not_negative`, `not_non_negative`, `not_non_positive`, `not_multiple_of`, `not_safe`, `invalid_enum_value` (`one_of`); integers also `not_int`.

## Integer-specific

`vld::number().int().int_error("Whole numbers only")` sets the message for a number with a fraction (`with_messages` key `not_int` does the same).

## Refinements

`refine(check, "message")`, `custom(|v| Err("message".into()))` and `super_refine` take the message directly.

## Messages and translations

Custom messages are kept by [`translate_error`](/errors/i18n): only default English messages are translated. Write custom messages in the target language, or leave them out and use translation tables.
